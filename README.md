## Things I've built

### [Enerlytics AI](https://github.com/LavdeepSingh23/Unsupervised-Energy-Optimization-Analytics)

ML-driven energy analytics for smart buildings.

- 52,585 buildings analysed
- PCA + K-Means behavioural segmentation
- 4 behavioural clusters
- Streamlit analytics dashboard
- anomaly detection and optimization insights
- up to $0.3M in potential energy savings identified

### [AcadHub](https://github.com/LavdeepSingh23/AcadHub)

A centralized academic platform combining LMS, WebKiosk and PYQ workflows.

- MySQL + PL/SQL
- 12 interconnected entities
- role-based access control
- procedures, triggers, views and transactions
- 10+ academic analytics reports

### Stack Overflow Duplicate Detection

Research project exploring unsupervised approaches for detecting semantically similar programming questions.

- TF-IDF
- Sentence-BERT
- K-Means
- DBSCAN
- cluster purity and recall evaluation

### [Enhanced Diabetes Prediction](https://github.com/idklol22/Enhanced-Diabetes-Prediction-using-Ensemble-Learning-and-SparsePCA-based-Feature-Reduction-)

An ML project that eventually became an IEEE conference publication.

- Sparse PCA
- Random Forest
- XGBoost
- CatBoost
- Optuna
- 94.6% accuracy
- 92.9% F1-score
